# ImagineYourBook: whole-book AI drafting with series continuity

ImagineYourBook is a paid web app for turning a brief (or an uploaded manuscript) into a full book draft, in the same broad category as [Sudowrite](sudowrite.md) and [NovelCrafter](novelcrafter.md), but oriented around finishing an entire manuscript workflow (plan → chapters → cover → export) rather than only scene-level co-writing.

## What it actually is

A browser-based book-writing product. Documented capabilities include:

* **New Book** — expand an idea, outline, or brief into a structured manuscript chapter by chapter.
* **Series story bibles** — carry characters, canon, voice, and open threads into later volumes.
* **Manuscript Rewrite** — upload existing Word / Markdown / text / HTML and request structural or voice changes while keeping the original source.
* **Export** — Word, EPUB, and Markdown, plus a generated cover image.
* **Author review** — product messaging treats output as a draft to review before publishing.

## Setup

1. Open [imagineyourbook.com](https://www.imagineyourbook.com).
2. Start from a prompt/brief (New Book) or upload an existing manuscript (Manuscript Rewrite).
3. Configure genre, POV, characters, and continuity rules as offered in the flow.
4. Generate the draft, then download Word/EPUB/Markdown and review before any publish step.

## How authors typically use it

* **Brief → full draft** when the bottleneck is finishing a complete first manuscript.
* **Series continuation** when book two must remember book one’s characters and open threads.
* **Rewrite mode** when an existing draft needs expansion, modernization, localization, or chapter surgery.
* **Export + human edit** before KDP or other retailers — the site emphasizes author review and commercial rights to generated output.

## Gotchas

* Long-form AI prose still needs human revision; treat the download as a draft.
* Retailer policies (e.g. Amazon KDP AI disclosure) are the author’s responsibility.
* Features and plan limits change; trust the live site over any static list card.
* This is a hosted SaaS workflow, not a local BYOK codex IDE like NovelCrafter.
